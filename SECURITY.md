# Security reports

Report suspected vulnerabilities privately to
[legaturi.ace7b@icloud.com](mailto:legaturi.ace7b@icloud.com), including the app
version, a concise description and sanitized reproduction steps. Do not post
credentials, private network details or unpatched vulnerability details in a
public issue. No response-time guarantee or bug-bounty program is offered.

This integration communicates with a CCM15 gateway on a reachable local
network. Its source repository contains generic code and fixtures, not an
installation's credentials or Homey/device configuration. The app does not
change gateway firmware. See [setup and scope](docs/PUBLIC_SETUP.md).
