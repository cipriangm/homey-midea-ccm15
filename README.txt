Make every room comfortable with your existing Midea VRF installation. Connect Homey Pro directly to a CCM15 gateway on your local network, see the temperature and current settings for each indoor unit, and build daily routines with Flow. Find local gateways and import indoor names already configured in CCM15. No Midea cloud account or Home Assistant is required.

This community integration supports CCM15 gateways that expose the local web interface. New devices begin with monitoring enabled; configure the indoor type, gateway compatibility and any shared outdoor circuit before enabling control in device settings. Room temperature comes from the indoor unit. Swing and auxiliary electric heat are available only when the relevant hardware is configured. A gateway address can also be entered manually.
