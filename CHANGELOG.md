# Changelog

Version 0.1.13 is a certification candidate. A GitHub release does not itself establish Homey App Store approval.

## 0.1.13

Update the App Store name to Midea, add a public support contact and replace the app cover with official Midea lifestyle photography. CCM15 support and device controls are unchanged.

## 0.1.12

Fix pairing navigation after selecting a gateway. Show a clear completion message when all indoor units are already added, preserve Homey view globals, and allow returning to gateway selection.

## 0.1.11

Find CCM15 gateways on the local network, import configured indoor names, and show gateway information. Existing device names and Flows are preserved.

## 0.1.10

Confirm power Off when an indoor reports its fan stopped, while retaining strict running-state checks and preserving command parameters. Improve inactive limit and restriction status, local Flow controls, delayed confirmation and device pairing.

## 0.1.9

Confirm power Off when swing stops with the indoor, while preserving its command parameter. Refuse enabling swing on an Off indoor and prevent Fan Off requests from silently becoming Auto.

## 0.1.8

Allow up to 30 seconds for delayed gateway state confirmation, while sending each command only once.

## 0.1.7

Clear No limit and Unlocked status displays; retain diagnostic fallback states and existing Flow tags and device settings. Prepare the community CCM15 listing and generic pairing setup.
